# Racall 0.2 Beta — in development

Not published. The public download remains [0.1 Beta](https://github.com/SleepyCodeMeow/Racall/releases/tag/v0.1.0-beta.1). This document describes the first development slice on `development/0.2`, not completion of the whole release.

## Implemented in the first slice

- Notebook-scoped chat history: create, select, rename and delete conversations. Questions, answers, search results and citation snapshots survive an app restart. Deleting a chat moves its transcript to the notebook's `trash/chats` directory.
- Interrupted requests are marked explicitly after restart. Opening a saved conversation does not call the model again. Request IDs prevent duplicate generation when the same request is replayed.
- Markdown note autosave after a typing pause, with newer keystrokes retained while an older save finishes. Existing frontmatter and aliases are preserved.
- Revision checks prevent silent replacement of a note already changed by another editor. Recovery drafts survive restart; save a separate copy or explicitly reload the external file. Further edits refresh the conflict draft.
- A localized close warning keeps the local service alive when the user chooses to continue editing an unsaved note.
- Feature folders for chats, notes, sources, research, settings and connections. See the [code map](../CODE_MAP.md) and [architecture decision](../adr/0012-feature-organization-and-persistence.md).

## Verification

On Windows, 31 Python tests, Ruff, TypeScript, 240-key EN/RU localization checks, release metadata checks and production frontend/backend builds passed. The unpacked Windows application passed the existing desktop and language scenarios plus the new persistence scenario: full restart, saved citations, delayed save responses, cancelling close while dirty, external-edit conflict, continued editing of the recovery draft, saving a copy and notebook isolation. The model in these tests is a deterministic local stub; this does not establish real-model answer quality.

See [verification records](../VERIFICATION.md) for local evidence and remaining platform checks.

## Limits and remaining 0.2 work

- Chat history is persistent, but prior turns are not yet sent as conversational context to the model.
- Changes not yet received by the local service can still be lost on an abrupt process or OS crash. Revision checks do not make simultaneous writes by separate editors transactional.
- No chat-trash restore interface is included yet. Back up the complete knowledge directory with Racall closed; chats and drafts contain user text.
- Notebook rename/delete, source refresh/version handling, parser process limits, real cloud/Ollama evaluation and native installation checks remain on the [0.2 roadmap](../ROADMAP.md).
- This development slice does not publish installers or replace the existing 0.1 release. Platform CI, clean installation checks and signing/notarization status must be assessed before release.
