# Racall 0.2 Beta

Your sources, cited answers and connected notes in one place. Racall is an open-source desktop alternative to NotebookLM + Obsidian.

**0.2 Beta brings saved chats, safer note editing, source history, more AI connections and a new light/dark workbench. This release is for Windows x64.**

## What's new

### Keep your conversations and notes

- Chats now persist across restarts, including answers, search results and exact citation snapshots. Rename or remove a chat; interrupted questions remain visible without being sent again automatically.
- Markdown notes autosave in order. Recovery drafts, external-edit conflict detection and a save-copy option help protect your work. Frontmatter and aliases are preserved.
- Rename notebooks, move them to recoverable trash and restore their notes, chats and sources. Active import/model work prevents notebook removal.

### Update sources without losing old citations

- Replace imported files and refresh public web sources.
- Source history preserves older originals and passages. A past citation opens the version used for that answer.
- A failed replacement keeps the previous working source and search index available.

### Choose your AI connection

- OpenAI, Claude, Ollama Local/Cloud and llama.cpp, plus custom OpenAI-compatible endpoints.
- Separate answer profiles keep saved URLs and model choices when switching providers. Optional embeddings are configured independently.
- Claude uses its native Messages API. Credentials stay in operating system secret storage.
- A searchable model picker beside the message box reads the saved provider's model catalog and supports manual model IDs.

Each user supplies their own provider access. These API connections are separate from Claude Code or Codex CLI subscriptions. See the [provider guide](https://github.com/SleepyCodeMeow/Racall/blob/v0.2.0-beta.1/docs/PROVIDERS.md).

### A quieter workbench

- Light, Dark and System appearance, saved independently of language and provider settings.
- Local Ollama downloads with explicit confirmation, current-layer progress and cancellation. Restart marks interrupted downloads without replaying them. Opening or selecting a model never starts generation or a download.
- Apps copies fixed Ollama launch commands for Claude Code, Codex CLI and other external tools. Paste a command into your own terminal when you want to run it; Racall does not execute it or install the tool.
- A compact light Windows installer with a native title bar, English/Russian selection, automatic installation location and a simple extraction progress screen.

## Fixes and reliability

- Protect pending note edits when opening Apps/settings, switching notebooks or receiving a delayed notebook-creation response. Keep recovered conflicts accessible for resolution.
- Recover unfinished Research as interrupted after restart, preserving its saved question and steps without automatically repeating model calls.
- Validate explicit claim references, bound answer-language repair and localize Research source headings while preserving original quotations.
- Bound completion streams, response size and timeouts. Truncated or aborted output cannot become an accepted answer, and inference is not retried automatically.
- Isolate file/web parsing in a supervised process with time and memory limits. This reduces resource risk; it is not a security sandbox.
- Show a selectable command if clipboard copying fails and clear stale success feedback.
- Use catalog metadata for cloud/local/server icons; unresolved Ollama aliases stay neutral after restart until their type is known.

Feature folders and a [code map](https://github.com/SleepyCodeMeow/Racall/blob/v0.2.0-beta.1/docs/CODE_MAP.md) make it easier to find and change individual workflows.

## Upgrade and known limits

**Back up the full knowledge folder with Racall closed before upgrading.** Settings shows its location. Existing 0.1 notebooks are supported on upgrade; downgrading new versioned 0.2 sources or provider settings is not guaranteed. The Windows installer is unsigned. Packaged checks used isolated profiles, and native install/uninstall checks ran on a disposable CI host rather than the owner's computer. These checks do not cover every interactive Windows security/permission dialog.

- Saved chat history is not yet supplied as conversational context to the model.
- Research stops when the app closes. It is marked interrupted after restart and must be requested again explicitly.
- An abrupt crash can lose keystrokes that have not reached the service. External-editor revision checks are not filesystem transactions.
- Source versions and notebook trash are retained; a permanent-delete interface is not included.
- OCR, sync, mobile apps, graph view, presentations/audio generation and remote MCP/OAuth remain future work.
- Cloud answers send questions and retrieved passages to the selected provider; cloud embeddings also send extracted document text.
