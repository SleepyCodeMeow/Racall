# Racall 0.1 Beta

Your notes. Your sources. Connected.

The first beta brings notebooks, local source files, Markdown notes, cited answers and research into one desktop workspace. Connect your own OpenAI-compatible provider or Ollama; import, notes and text search work without a model.

## Downloads

Pick the asset for your platform:

| Platform | Filename |
| --- | --- |
| Windows x64 | `Racall-0.1.0-beta.1-win-x64.exe` |
| macOS Apple Silicon | `Racall-0.1.0-beta.1-mac-arm64.dmg` or `.zip` |
| macOS Intel | `Racall-0.1.0-beta.1-mac-x64.dmg` or `.zip` |
| Linux x64 | `Racall-0.1.0-beta.1-linux-x64.AppImage` or `.deb` |

Use the actual attached release assets; source-code archives are not installers. `SHA256SUMS.txt` contains hashes for all packages. Packages are unsigned and macOS packages are not notarized. No system Python or Node.js installation is required.

## Included

- PDF with a text layer, Markdown, TXT, DOCX and public HTML URL import.
- Local keyword search and optional provider embeddings.
- AI answers with citation validation, a model critic and exact passage inspection.
- Markdown notes, frontmatter, wikilinks and research reports.
- Read-only, notebook-scoped MCP over stdio.
- English by default, Russian in Settings; Windows installer language carries into first launch.

## Verification and limits

The release workflow requires backend tests, lint, localization checks, version checks, production builds, packaged desktop smoke tests and frozen-backend PDF tests on all four target OS/architecture combinations. CI success covers those automated scenarios; manual clean installation/uninstallation on every OS is still required before a stable release. A local Windows packaged smoke test is also available.

AI behavior is covered with deterministic mock providers, not a real cloud/Ollama model evaluation. Provider compatibility and answer quality vary. Inspect source citations. Cloud inference sends the question and relevant passages to the configured provider; cloud embeddings send extracted text.

Chat history is not persisted. Save notes explicitly. Research is synchronous and is interrupted on app close. No OCR, mobile app, sync, graph view, source refresh, notebook rename/delete, remote MCP/OAuth or automatic updater in this beta. Back up the knowledge directory before upgrading.
