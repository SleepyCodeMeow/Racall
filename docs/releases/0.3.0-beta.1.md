# Racall 0.3 Beta

Your sources, cited answers and connected notes in one place. Racall is an open-source desktop alternative to NotebookLM + Obsidian.

**0.3 Beta brings conversational context, selected sources and saved notes, and reusable Research/Studio materials. Downloads now cover Windows, macOS and Linux on x64 and ARM64.**

[New features](#new-features) · [Downloads](#downloads--upgrade) · [Known limits](#known-limits) · [Documentation](https://github.com/SleepyCodeMeow/Racall/blob/v0.3.0-beta.1/docs/README.md) · [Report an issue](https://github.com/SleepyCodeMeow/Racall/issues/new/choose)

## New features

- **Follow-up questions use the active chat.** In 0.2, chats were saved but their history was not supplied to the model. Bounded thread history now helps resolve follow-ups; previous assistant prose remains context rather than factual evidence.
- **Choose the evidence.** Select imported sources and saved notes for chat, Research and Studio, including an explicitly empty selection. Your selection survives restart, and citations retain the source version or note revision used for the answer.
- **Create three kinds of text material.** Studio adds summaries, study guides, and review questions with answers. Generate from your selected material, then inspect the cited passages.
- **Keep generation work visible.** Research and Studio use durable jobs with stage progress, duplicate-submission protection, queued/running cancellation and explicit retry. Restart marks unfinished work as interrupted without automatically repeating model requests. A retry uses current material versions and saved AI settings.
- **Build a reusable library.** Keep materials independently of chat deletion, export cited Markdown, or make an editable note copy while retaining the original. Earlier 0.2 Research reports remain accessible.

See the [context and Studio guide](https://github.com/SleepyCodeMeow/Racall/blob/v0.3.0-beta.1/docs/STUDIO.md).

## Fixes & under the hood

- Keep selected context and revision snapshots consistent through generation; prevent cancelled or interrupted jobs from publishing a late result.
- Report a missing model name before creating a background generation job. Keep credentials out of durable job/material metadata.
- Split Python retrieval, generation, document processing and completion protocols into focused modules. Python remains the primary application language; frontend controllers/views and Electron lifecycle/security/native actions have clearer boundaries too.
- Share note parsing between the editor and citation snapshots. Add formatting checks, an updated [code map](https://github.com/SleepyCodeMeow/Racall/blob/v0.3.0-beta.1/docs/CODE_MAP.md) and a [contributor development guide](https://github.com/SleepyCodeMeow/Racall/blob/v0.3.0-beta.1/docs/DEVELOPMENT.md).

Candidate verification covered **499 Python tests per native target**, packaged workflows, installation/copy checks and a separate installed Windows x64 **0.2 → 0.3** upgrade. One Windows/local Ollama configuration completed **25 functional scenarios**. See the [candidate report](https://github.com/SleepyCodeMeow/Racall/blob/v0.3.0-beta.1/docs/CANDIDATE_VERIFICATION_03_2026-10-25.md) and [model evaluation](https://github.com/SleepyCodeMeow/Racall/blob/v0.3.0-beta.1/docs/MODEL_EVALUATION_03_2026-10-25.md) for exact scope and limitations.

## Known limits

- **AI-generated content needs review.** Testing found unsupported paraphrases that the local critic accepted, despite correct citation bytes. An AI acceptance flag is not a factual guarantee. Inspect important claims, question premises and cited passages; the [model report](https://github.com/SleepyCodeMeow/Racall/blob/v0.3.0-beta.1/docs/MODEL_EVALUATION_03_2026-10-25.md) preserves both failures and successful workflows.
- **Unsigned beta distribution.** Windows installers are unsigned; macOS packages are unsigned and not notarized. There is no automatic updater. Native CI does not cover every OS version, physical device, Linux desktop or AppImage FUSE setup.
- **Limited live-model coverage.** The local Ollama run does not certify other models, cloud providers, llama.cpp or embeddings quality. Cancelling Racall's request does not guarantee immediate upstream GPU work stoppage.
- **Text materials first.** Presentations, generated audio/video, OCR, interactive quizzes/flashcards, mobile apps and sync remain future work.

The [0.3 checklist](https://github.com/SleepyCodeMeow/Racall/blob/main/docs/RELEASE_03_CHECKLIST.md) records the verification scope. Earlier candidate reports retain the status that applied when their checks ran.
