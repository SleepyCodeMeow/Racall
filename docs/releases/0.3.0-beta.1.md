# Racall 0.3 Beta — in development

**Not published. Publication is on hold.** The current public Windows download remains [0.2 Beta](https://github.com/SleepyCodeMeow/Racall/releases/tag/v0.2.0-beta.1). Development proceeds in feature modules; no release date has been chosen.

## Accepted development scope

- Bounded history for the active chat, with explicit source and saved-note context selection. Earlier assistant prose is conversation context, not independent factual evidence.
- Durable Research and Studio generation jobs with stage progress, cancellation, idempotent submission and explicit retry after interruption. No automatic replay of unfinished model calls.
- Three text-only Studio presets: concise summary, study guide, and review questions with answers. Keep source/note provenance, English/Russian behavior and editable Markdown copies.
- A persistent material library independent of chat deletion, including compatible access to 0.2 Research reports.

Implementation and verification status are tracked in the [0.3 checklist](../RELEASE_03_CHECKLIST.md). These scope items are not release-readiness or live model-quality claims.

The development implementation now includes this workflow; see the [context and
Studio guide](../STUDIO.md). Python remains the primary application language,
with TypeScript/JavaScript limited to the interface and desktop integration.

## Boundaries

The candidate matrix now targets Windows x64/ARM64, macOS x64/ARM64 and Linux
x64/ARM64. Native build and package acceptance must pass separately for each
target; Windows tests do not establish macOS/Linux acceptance. All six native
candidate jobs passed in [Actions run 40209217858](https://github.com/SleepyCodeMeow/Racall/actions/runs/40209217858).
See the [native verification report](../NATIVE_VERIFICATION_03_2026-10-25.md)
for the exact source, ten package checksums and test limits, and the
[native candidate scope](../NATIVE_CANDIDATES_03.md) for architecture details.
No Docker/WSL or real
local/cloud inference is required for deterministic development checks.

Slides, speech/video generation, OCR engines, interactive quizzes/flashcards, new languages, subscription/CLI model backends and mobile/sync are outside this slice. The published 0.2 tag and assets remain unchanged.
