## Статус перехода

README, интерфейс, заголовок окна, установщик и системные иконки используют Racall. Идентификатор установки, папка данных `OpenNotebook`, имена переменных окружения и namespace системного keyring сохранены для совместимости. Миграция и перемещение файлов не выполняются. Поддержка телефонов и планшетов остаётся планом, а не возможностью версии 0.3.

`assets/brand/racall-desktop-preview.png` — снимок настоящего интерфейса 0.3 с демонстрационными материалами и декоративной внешней подложкой. На снимке используется светлая тема; приложение также поддерживает тёмную и системную. Снимок воспроизводится командой `node scripts/capture-readme.cjs` после сборки frontend; сценарий использует изолированное хранилище в `test-results`, Python backend и headless Chromium с отключённым GPU. Модели и внешние сервисы не вызываются. На Windows по умолчанию используется установленный Chrome; путь можно передать через `RACALL_BROWSER_PATH`.
