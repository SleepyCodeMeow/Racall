# Maintainability refactor for 0.3 Beta

Publication remains on hold. This is a behavior-preserving refactor of the
accepted 0.3 scope, not a feature expansion or a version change.

## Responsibilities made explicit

- Python: document models/parsers/web fetching/chunking in `documents/`; evidence
  search and ranking in `retrieval/`; writer/critic and Research in `generation/`;
  strict JSON/SSE/OpenAI decoding in `completion/`. Existing public facades keep
  the application, parser-worker and completion entry points recognizable.
- Feature services: model discovery and download protocol separated from task
  lifecycle; job execution separated from queue/credentials/final commit; one
  note Markdown decoder shared by persistence and selected-note context.
- Interface: workspace, chat and source detail have controller hooks and focused
  view components. HTTP client, DTOs, native bridge declarations, original-file
  URLs and citation labels have separate modules. CSS moved to named shared and
  feature sheets while retaining the original import/cascade order.
- Electron: lifecycle, runtime paths, Python process, trusted-session policy,
  window behavior and fixed native actions live in separate modules.
- Tooling: pinned Prettier and Ruff formatting, editor/line-ending defaults,
  `npm run format`, `npm run format:check` and a native CI formatting gate.
- Contributor navigation: refreshed [architecture](ARCHITECTURE.md),
  [code map](CODE_MAP.md), [development tour](DEVELOPMENT.md) and contribution guide.

Small cohesive modules and sequential end-to-end scenarios were retained. No
extra framework or one-file-per-function requirement was introduced. Core behavior
stays in Python; the interface and Electron do not acquire AI or storage policy.

## Compatibility and review

API payloads, portable file formats, source IDs/versions, note revision hashes,
profile paths, provider credentials and model settings remain unchanged.
Independent source comparisons checked moved parser/ranking/generation/protocol
function bodies, queue/cancellation scopes, frontend state/actions and expanded
CSS rule order. Tests are the behavioral check; source comparison alone is not
release acceptance.

Seven regression cases cover shared note/frontmatter parsing and revision/context
consistency, including malformed and custom frontmatter. Existing tests were not
weakened. Two implementation-specific test imports now point to the moved ranking
and Research provider responsibilities.
