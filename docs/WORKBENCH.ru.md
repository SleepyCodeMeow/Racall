# Приложения, модели и темы

[English guide](WORKBENCH.md) · [Настройка провайдеров](PROVIDERS.ru.md) · [Карта кода](CODE_MAP.md)

В Racall остаются компактная боковая панель, спокойный экран чата и оранжевый енот. В настройках доступны **Светлая**, **Тёмная** и **Системная** темы. Выбор сохраняется в `appearance.json` профиля отдельно от языка и ключей. Системная тема реагирует на изменения оформления устройства; рамка окна Electron остаётся нативной.

## Выбор модели возле сообщения

Нажмите кнопку модели рядом с отправкой сообщения. Выберите сохранённое подключение, найдите модель и выберите её. Меняется только модель ответов: эмбеддинги и остальные профили независимы. Адрес сервера и ключ настраиваются в разделе подключения. Можно вручную ввести ID, если сервер не предоставляет список моделей.

Список приходит от выбранного провайдера: нативный `/api/tags` Ollama, `/models` Claude или совместимый с OpenAI `/models`. Открытие списка и выбор не запускают генерацию. Для облака нужны подходящие аккаунт, ключ и разрешения провайдера.

Чтобы скачать модель через **локальную Ollama**, раскройте **Ввести ID модели**, укажите точное название из библиотеки, нажмите **Скачать через Ollama** и подтвердите. Racall отправит потоковый запрос `/api/pull` в сохранённую локальную Ollama. Индикатор показывает **текущий слой**, а не процент всей модели. Скачивание не запускает модель и не выбирает её автоматически. После завершения список обновится, и модель можно выбрать.

Отмена закрывает запрос Racall. Ollama может оставить частично скачанные файлы в кэше; другой клиент может продолжать загрузку того же блока. Racall не останавливает службу и не удаляет модели. После перезапуска незавершённая загрузка помечается прерванной; для продолжения нужно снова явно запустить скачивание. Облачные модели работают удалённо, их веса не скачиваются.

## Приложения

Здесь собраны фиксированные команды Ollama для Claude Code, Codex CLI, OpenCode, Cline, Copilot CLI, Qwen Code, Droid и Pi. Нажатие **копирует** команду, например `ollama launch claude`, и показывает её в уведомлении справа сверху. Вставьте команду в терминал для запуска. Настройка и вход выполняются самим инструментом; необходимы Ollama и выбранное приложение. Racall не выполняет команды и не устанавливает программы автоматически.

Если копирование не удалось, команда появится в поле только для чтения. Выделите её, скопируйте вручную и вставьте в терминал. Предыдущее уведомление об успешном копировании при ошибке убирается.

Внешние инструменты для разработки — отдельная функция. Провайдеры моделей отвечают за ответы внутри Racall, а раздел подключения MCP предоставляет доступ к конкретному блокноту.

## Проверки

`npm run test:workbench` проверяет интерфейс с изолированным тестовым сервером. Обращаться к пользовательской Ollama или облачному аккаунту он не должен. Этот сценарий включён в `npm run test:packaged` вместе с проверками провайдеров, сохранения данных, языков и собранного сервиса. Результаты и ограничения описаны в [отчёте](WORKBENCH_2026-10-17.md).
