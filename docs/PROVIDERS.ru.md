# Подключения AI в 0.2 Beta

[English instructions](PROVIDERS.md) · [Проверка модели](MODEL_EVALUATION.ru.md)

Открой **Настройки → Подключение AI**, выбери провайдера, укажи точное имя модели и сохрани. Для каждого провайдера сохраняется свой адрес и модель. У Ollama локальный сервер и прямое облачное API имеют отдельные профили. [Выбор модели возле сообщения](WORKBENCH.ru.md) получает список от сохранённого подключения; скачивание через локальную Ollama требует отдельного подтверждения. Racall не запускает генерацию и не переключается в облако автоматически.

| Подключение | Что указать |
| --- | --- |
| OpenAI | API-ключ OpenAI и модель с поддержкой Chat Completions и JSON |
| Claude | API-ключ Anthropic и точный идентификатор модели Messages API |
| Ollama → Локально | Запущенную Ollama и имя скачанной модели из `ollama list` |
| Ollama → Облачное API | API-ключ Ollama и имя облачной модели из её каталога |
| llama.cpp | Запущенный `llama-server` с GGUF-моделью, его адрес и имя/alias модели |

Локальный адрес Ollama означает подключение к установленному серверу. Если выбрать в нём облачную модель и войти в аккаунт Ollama, запрос всё равно уйдёт в облако. Для работы без интернета выбирай скачанную локальную модель. Прямое облачное API Ollama не требует установленной Ollama. [Документация](https://docs.ollama.com/api/authentication).

Эти подключения используют API. Раздел [«Приложения»](WORKBENCH.ru.md) отдельно копирует команды запуска внешних инструментов через Ollama, включая Claude Code и Codex CLI; вход выполняется самим инструментом в терминале. Их подписки не становятся API-ключами Racall. OpenAI API имеет отдельную оплату от включённых лимитов подписки ChatGPT. Используется доступ самого пользователя, общих встроенных ключей нет.

Ключи сохраняются в системном хранилище секретов и привязаны к URL API. Подключения с одинаковым URL используют один ключ; два разных ключа для одного адреса отклоняются. Пустое поле сохраняет существующий ключ. В `settings.json` и ответах API самих ключей нет. При сохранении записывается ключ текущего провайдера; подсказка сообщает о несохранённых ключах других подключений. Сохрани их отдельно до выхода из настроек.

Вопросы и найденные фрагменты отправляются выбранному серверу ответов. При облачном подключении они обрабатываются удалённо. Локальное хранение заметок не означает, что облачная модель работает на твоём компьютере.

В разделе **Семантический поиск** можно отдельно настроить embeddings через OpenAI, Ollama, llama.cpp или совместимый сервер. При этом отвечать может Claude. Сохраняется выбранное подключение embeddings; пустое имя модели оставляет обычный текстовый поиск. После смены адреса или embedding-модели перестрой индекс блокнота. Смена только модели ответов не сбрасывает совместимые embeddings.

Старые настройки отображаются как пользовательское OpenAI-совместимое подключение. Само чтение не переписывает файл. Сохранение переводит его в формат профилей; старые адреса, модель и embedding-подключение сохраняются. Перед обновлением сделай резервную копию каталога знаний: прежняя версия приложения не понимает новый формат настроек.

Обрыв потока, отказ модели и исчерпание лимита ответа не становятся подтверждённым ответом. Для одного обращения действует общий предел 300 секунд и предел бездействия 120 секунд; Research может делать несколько обращений. Цитаты проверяются после завершения генерации.
